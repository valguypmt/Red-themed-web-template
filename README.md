# Red-Themed Web Template

A dark, red-accented static website template built with HTML, CSS, and JavaScript. The project combines a full-width header, sticky sidebar navigation, reusable content cards, and a multi-column footer with Lorem Ipsum placeholder content.

## Features

- Red and charcoal visual theme
- Sticky or horizontal sidebar navigation
- Scroll reveal animation for content sections
- Reusable text, image, table, quote, video, grid, and button cards
- Responsive layouts for desktop, tablet, and mobile
- Four-column footer that adapts to smaller screens
- Placeholder assets and sample pages that are ready to replace

## Built With

- HTML5
- CSS3
- JavaScript

## Template Components

The `Template/` folder contains standalone examples for common content layouts:

- Text only
- Text with an image
- Text with one or more buttons
- Text with tables
- Text with quote blocks
- Text with videos
- Text with image grids
- More combinations of text, images, tables, videos, and buttons

Open any file inside `Template/` directly in a browser to preview a layout.

## Customization

- Replace Lorem Ipsum text inside the HTML files.
- Update navigation links and page titles.
- Replace images inside `images/` or `Template/images/`.
- Adjust the accent color and visual styles in `style.css`.
- Add new sections using the existing `tweet-card` classes.
- Update `script.js` to change or extend scroll animations.
